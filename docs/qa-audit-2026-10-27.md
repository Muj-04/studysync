## Remaining confirmed findings and limits

1. **P2 — room reconciliation incomplete (code-path evidence).** Reconnect fetches strokes, not missed room voice-note/blank-page snapshots. Voice-note subscriptions handle INSERT/DELETE, not title UPDATE. A disconnected peer can retain stale state until reload. No hosted reproduction or privacy exploit is claimed.
2. **P2 — recording storage/metadata are non-atomic (local failure-path evidence).** A successful upload followed by signing/metadata failure can leave an orphan. A successful object removal followed by DB failure can leave metadata pointing at missing audio. The new PR surfaces errors; a coordinated server cleanup/retry design is still required. No orphan was created on staging.
3. **P2 — remote-absent text-page reconciliation remains ambiguous (static evidence).** Workspace still uploads locally cached text pages absent from the cloud response. Without distinguishing a genuinely new local page from remote deletion and failed reads, cross-device deletion can be undone. The focused hydration correction covers overlapping pages, not this legacy reconciliation policy.
4. **P2 — synchronization is not a complete offline system.** Drawing/blank pending markers preserve local intent but do not replay automatically; room audio retained after failure lives only in the tab. Browser storage exhaustion and concurrent cross-tab/device merges are not solved. Do not promise durable offline sync from these tests.
5. **P3 — maintainability/configuration.** 28 existing lint warnings, large workspace/room/community components and emulator/debug Android configuration remain. Components were not rewritten to meet size targets.

No P0 issue was demonstrated. Prior risk decisions remain open: immediate revocation of already-issued four-hour LiveKit tokens, long-lived audio URL policy, process-local AI throttling/trusted ingress, and referral-code collision recovery. These are not newly proven cross-account compromises.
